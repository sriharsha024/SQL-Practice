# SQL Practice Files 📊

This repository contains a comprehensive set of SQL practice files to help you learn, revise, and master core SQL concepts. The scripts cover everything from basic SELECT statements to advanced window functions.

## 📌 Description

A collection of SQL scripts including DDL, DML, filtering, joins, set operators, date/time functions, string/number functions, NULL handling, and window functions. Ideal for beginners and intermediate learners looking to strengthen their SQL skills with practical examples.

---

## 📂 Files Included

| File Name                             | Description                                                                 |
|---------------------------------------|-----------------------------------------------------------------------------|
| `Create tables.sql`                   | Scripts to create practice tables using DDL.                                |
| `DDL.sql`                             | Data Definition Language commands (CREATE, ALTER, DROP).                    |
| `DML.sql`                             | Data Manipulation Language commands (INSERT, UPDATE, DELETE).               |
| `Select Statements.sql`               | Basic `SELECT` queries to fetch data.                                       |
| `Filtering.sql`                       | `WHERE`, `BETWEEN`, `LIKE`, `IN`, `NOT` and logical operators.              |
| `Joins.sql`                           | Examples of INNER, LEFT, RIGHT, and FULL JOINs.                             |
| `New Database and Multiple joins.sql` | Creating a new DB and using multiple table joins.                           |
| `Case Statement.sql`                  | Usage of `CASE` for conditional logic in SQL queries.                       |
| `Set operators.sql`                   | Usage of `UNION`, `INTERSECT`, `EXCEPT`.                                    |
| `Null Functions.sql`                  | Handling NULL values with `ISNULL`, `COALESCE`, etc.                        |
| `Date & Time functions.sql`           | Manipulating dates and times using SQL functions.                           |
| `String & Number Functions.sql`       | Formatting and manipulating strings and numbers.                            |
| `Window aggregate.sql`                | Window functions with aggregation (e.g., `SUM() OVER()`).                   |
| `Window rank.sql`                     | Ranking functions like `RANK()`, `DENSE_RANK()`, `ROW_NUMBER()`.            |
| `Window value.sql`                    | Value-based window functions like `LEAD()`, `LAG()`, `FIRST_VALUE()`.       |
